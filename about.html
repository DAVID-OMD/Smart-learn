About SmartLearn

SmartLearn is a lightweight learning website for secondary school students. It provides short notes, interactive quizzes, and progress tracking without logins, databases, or internet access.

Our Goals

  • Make revision quick and accessible
  • Use active recall: quizzes with instant feedback
  • Work on any device with a web browser

How It Works

  1. Pick a mock user in the navbar (Guest / Test Student / Demo Teacher — test data only).
  2. Go to the Subjects page.
  3. Read the summary and click “Show Practice Set”.
  4. Click “Start Quiz” to test yourself and get a score.
  5. Click “Mark Complete” — progress is saved per mock user automatically.

FAQ

Do I need internet or an account?

No. Just open index.html. Pick a mock test user in the navbar — no passwords. Progress saves per mock user in your browser via localStorage.

How are best scores stored?

Per subject in your browser only. Use “Reset Progress” on the Subjects page to clear them.

Can teachers add questions?

Yes. Edit quizData and practiceData in script.js — no tools needed.

For Teachers & Parents

All files are plain HTML, CSS, and JavaScript. Copy the folder to any computer or USB drive and open index.html to run it.
